# 0.5.1 — 2026-10-08

## Changed

- **Tool and resource error `data` carries `requestId`**, and a tool error's text closes with `request <id>` (mcp-ts-core 0.13.10).
- **Error `data` no longer carries stack traces** (0.13.7), request context (0.13.8), or `rootCause` (0.13.13); fetch errors name a URL by origin only (0.13.12).
- **Tool-argument pre-validation repairs more inputs instead of rejecting them**: an integer sent for a string and a JSON-stringified object (0.13.9); numeric or boolean strings, a lone string for an array, and `null` at an optional key (0.13.14).
- **`ctx.fail` throw sites name only the reason**; the framework fills the declared `recovery` from the `errors[]` entry (0.13.10). Tests assert the hint on the contract path (`runToolContract`, the worker handler).
- **`server.json` npm entries set `runtimeHint: "npx"`** and drop the `run start:*` arguments; the `streamable-http` entry fixes `MCP_TRANSPORT_TYPE` as `http` (0.13.11).
- **Docker**: a `deps` stage on `$BUILDPLATFORM` cross-installs production dependencies with `--os`/`--cpu` (`scripts/install-otel.ts`, `scripts/prune-musl-packages.ts`), so a multi-arch build no longer runs Bun under QEMU; base images `oven/bun` 1.4.0 → 1.4.2; `ENV MCP_FORCE_CONSOLE_LOGGING` removed.
- **`.dockerignore` excludes every `.env*` file** and the MCP Registry token files; `.gitignore` ignores `.env*` except `.env.example`, `.env.template`, and `.env.sample`; `.mcpbignore` excludes `docs/idea.md` and `logs/`.
- **`package.json`** adds `"!dist/*.mcpb"` to `files` and `packageManager` `bun@1.4.2`.
- **`.env.example`** documents `MCP_REQUEST_STATE_KEY`, `LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, `LOG_LLM_INTERACTIONS`, and the per-signal `OTEL_EXPORTER_OTLP_*_ENDPOINT` variables.
- **`.github/workflows/codeql.yml`** runs a per-language matrix (`actions`, `javascript-typescript`), each uploading under `/language:<language>`.
- **Framework scripts resynced** (`devcheck`, `lint-mcp`, `lint-packaging`, `release-github`, `check-skill-versions`, `check-framework-antipatterns`): new Dockerfile build-platform and `server.json` launch-shape checks, tag-annotation validation, load-failure errors in `lint-mcp`, and macOS-safe TODO/secret-file scans.
- **`framework-skills/`** synced to mcp-ts-core 0.13.14; `CLAUDE.md`, `AGENTS.md`, and the README badges updated to the new framework, MCP SDK, and Bun versions.

## Fixed

- **`ris-service` debug log** `RIS content fetched` records the rendition file name (`file`) instead of the full URL.
