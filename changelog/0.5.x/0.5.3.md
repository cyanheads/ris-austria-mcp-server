# 0.5.3 — 2026-10-24

## Added

- **`ris_search_drafts` records add `review_start`, `abbreviation`, and `keywords`** where RIS sends them ([#68](https://github.com/cyanheads/ris-austria-mcp-server/issues/68)).
- **`ris_track_changes` consolidated-law rows add `in_force_from` and `in_force_until`**, rendered as `**In force:** <from> → <until>`; a row without an end date reads `→ no end date` ([#69](https://github.com/cyanheads/ris-austria-mcp-server/issues/69)).

## Changed

- **`page_size` accepts any whole number 1–100** on all six paginated tools: 1–10 is served as 10 and 11–100 as 20, with a `notice` when the served size differs; 0, fractions, and values above 100 are still rejected ([#70](https://github.com/cyanheads/ris-austria-mcp-server/issues/70)).
- **`ris_lookup_citation` returns `found: false` with an EUR-Lex link, before any RIS request,** for EU acts RIS does not consolidate (DSGVO, the Charter as GRC, EuGVVO, EuInsVO 2015, EuUVO) and for a cite led by a CELEX other than the TFEU's or TEU's; a leading TFEU/TEU CELEX is dropped and the rest resolves ([#67](https://github.com/cyanheads/ris-austria-mcp-server/issues/67)).
- **`ris_search_legislation` renders a version without `in_force_until` as `→ no end date`** instead of "still in force" ([#69](https://github.com/cyanheads/ris-austria-mcp-server/issues/69)).

## Fixed

- **`ris_lookup_citation` resolves comma-joined norms** ("DSG §1, §24"): the first provision resolves and `resolution_note` names the rest as their own cites ([#72](https://github.com/cyanheads/ris-austria-mcp-server/issues/72)).
- **`celex_references` holds only CELEX numbers**: annotation text such as `(EWR/Anh. IX)` no longer appears as entries ([#71](https://github.com/cyanheads/ris-austria-mcp-server/issues/71)).
- **Begut and RegV `abbreviation` is trimmed**, matching consolidated law ([#68](https://github.com/cyanheads/ris-austria-mcp-server/issues/68)).
