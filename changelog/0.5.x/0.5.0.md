# 0.5.0 — 2026-09-24

## Changed

- **`ris_get_document` html/xml over 40,000 bytes returns `kind: "link"`** — no text, `truncated: true`, the full `byte_size`, and `content_urls`; it previously returned the whole rendition as `kind: "full"`. Nearly every HTML rendition lands here, so read with `markdown` ([#36](https://github.com/cyanheads/ris-austria-mcp-server/issues/36)).
- **Raw html/xml text is fenced in `content[]`**, with a fence longer than any backtick run in it, so markup reaches the client verbatim ([#36](https://github.com/cyanheads/ris-austria-mcp-server/issues/36)).
- **`page_size` accepts only 10 or 20** on the six paginated tools; 50 and 100 are rejected at the schema — raise `page` to read further ([#40](https://github.com/cyanheads/ris-austria-mcp-server/issues/40)).
- **Blank or whitespace-only text filters are rejected** on the five search tools (`filterText`, advertised as a JSON Schema `pattern`); omit the field to leave it unfiltered ([#39](https://github.com/cyanheads/ris-austria-mcp-server/issues/39)).
- **`changed_since` is rejected with `collection: "social_insurance"` or `"veterinary"`** on `ris_search_announcements`, where RIS ignores it; the recovery names `published_from` and `ris_track_changes` ([#37](https://github.com/cyanheads/ris-austria-mcp-server/issues/37)).
- **A ministry the target issuer parameter does not accept fails as `unresolved_ministry`**, naming the parameters that do accept it. `ris_search_drafts`, `ris_search_gazette`, and `ris_search_announcements` declare the reason, which also covers the unknown and ambiguous abbreviations previously reported as `invalid_query` ([#45](https://github.com/cyanheads/ris-austria-mcp-server/issues/45)).
- **Social-insurance `issuer` expands carrier abbreviations** (`ÖGK`, `DVSV`, `SVS`, …) to the exact `Urheber` value, case-insensitively; any other value is sent as written ([#38](https://github.com/cyanheads/ris-austria-mcp-server/issues/38)).
- **`ris_list_reference`**: `issuing_bodies` shows each carrier's accepted abbreviation, `ministries` lists the 2025 ministries, and `collections` lists `changed_since` only where RIS honors it.

## Fixed

- **The ministries in office since 2025 resolve** — BMASGPK, BMEIF, BMFFJI, BMFI, BMFWF, BMIMI, BMLUK, BMWET, BMWKMS. A full designation missing from the table (any value containing a space) is now sent to RIS unchanged instead of rejected ([#44](https://github.com/cyanheads/ris-austria-mcp-server/issues/44)).
- **`document_url` accepts `https://ogd.ris.bka.gv.at`**, the host search results now carry, alongside `https://www.ris.bka.gv.at`; the origin match stays exact ([#43](https://github.com/cyanheads/ris-austria-mcp-server/issues/43)).
