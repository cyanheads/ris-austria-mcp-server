# 0.5.2 — 2026-10-17

## Added

- **`ris_lookup_citation` resolves ECLIs** ("ECLI:AT:VFGH:2026:G13.2025"), **court-prefixed case numbers** ("VfGH G 13/2025"), and **year-first gazette cites** ("BGBl I 2018/24") ([#50](https://github.com/cyanheads/ris-austria-mcp-server/issues/50)).
- **Server instructions** at `initialize`: the entry point per input, the `document_number` and application pairing, and the binding rule ([#57](https://github.com/cyanheads/ris-austria-mcp-server/issues/57)).
- **`ris_search_gazette` records add `celex_references`** (`[]` when none), **`systematic_number`** (Niederösterreich Gliederungszahl), **`issue`**, and **`start_page`** ([#55](https://github.com/cyanheads/ris-austria-mcp-server/issues/55)), and **`promulgation`**, the gazette that carried a 1848–2003 federal entry ([#65](https://github.com/cyanheads/ris-austria-mcp-server/issues/65)).
- **`ris_search_legislation` records add `keywords`** ([#63](https://github.com/cyanheads/ris-austria-mcp-server/issues/63)); RIS's `<br/>` keyword-group breaks join with a comma on every tool.
- **`ris_track_changes` rows add `section_label` and `law_id`** (BrKons, LrKons) and **`case_numbers` and `decision_date`** (court decisions) ([#56](https://github.com/cyanheads/ris-austria-mcp-server/issues/56)).
- **`ris_search_announcements` records add** `case_numbers`, `type`, `in_force_from`/`in_force_until`, `keywords`, `note`, `court_name`, `plan_state`, `session_number`, `legislature`, and a decree's `approved`, `department`, and `promulgation`; a decree's `norms_cited`, always empty before, is populated ([#54](https://github.com/cyanheads/ris-austria-mcp-server/issues/54)).

## Changed

- **State parameters accept German and English state names** ("Tirol", "niederösterreich", "Vienna") on `scope` (legislation, gazette), `state` (case law, lookup), and `plan_state` (announcements) ([#58](https://github.com/cyanheads/ris-austria-mcp-server/issues/58)).
- **`ris_search_case_law` `decision_type: all` (the default) also searches decision texts on `vfgh`, `vwgh`, and `justiz`**, which returned Rechtssätze only, so totals rise ([#62](https://github.com/cyanheads/ris-austria-mcp-server/issues/62)).
- **`ris_search_announcements` `type` is checked locally** on `court_rules`, `trade_exam_rules`, and `veterinary`, in any letter case; `trade_exam_rules` lists all five values and `Undefined` searches unfiltered ([#59](https://github.com/cyanheads/ris-austria-mcp-server/issues/59)).
- **`ris_search_case_law` `issuing_body` is checked locally** on `dsk` and `pvak`, and `dsk` accepts `ParlamentarischesDatenschutzkomitee` (2025+) ([#61](https://github.com/cyanheads/ris-austria-mcp-server/issues/61)).
- **A value rejected locally recovers by naming the field to correct**; its `invalid_query` recovery no longer opens with paging advice.
- **`framework-skills/`** synced to mcp-ts-core 0.13.15; `CLAUDE.md`, `AGENTS.md`, and the README badges updated to the new framework, MCP SDK, and Bun versions; Dockerfile base images and `packageManager` move to Bun 1.4.3.

## Fixed

- **`ris_lookup_citation` picks the cited document, not the first hit** ([#48](https://github.com/cyanheads/ris-austria-mcp-server/issues/48)): a norm resolves to the law whose abbreviation is cited ("§ 2 EStG" → EStG 1988), a case number to its decision text before its Rechtssätze, and a gazette cite to the gazette it names. A partless "BGBl. Nr. 50/2025" matching parts I, II, and III returns `found: false` naming each.
- **Geschäftszahl court detection** covers VfGH numbers without a space, VwGH `Fr`/`AW` and pre-2014 numbers, BVwG hyphenated and `I`-chamber numbers, and the LVwG formats ([#49](https://github.com/cyanheads/ris-austria-mcp-server/issues/49)).
- **`ris_lookup_citation` "N more matched" recipe carries the filter that matched**, so running it lists the alternatives counted ([#64](https://github.com/cyanheads/ris-austria-mcp-server/issues/64)).
- **"StGBl. Nr. 1/1945" resolves**; the 1918–1920 StGBl. and changeover-year numbers pick the cited gazette ([#65](https://github.com/cyanheads/ris-austria-mcp-server/issues/65)).
- **`ris_search_legislation` `abbreviation` is populated** for consolidated federal and state law ([#51](https://github.com/cyanheads/ris-austria-mcp-server/issues/51)).
- **`case_numbers` holds one Geschäftszahl per element**: a Justiz headnote's `;`-joined list and companions are split ([#53](https://github.com/cyanheads/ris-austria-mcp-server/issues/53)).
- **`ris_get_document` markdown prints each Absatz, Ziffer, and litera under its RIS label**, with no generated list number ([#52](https://github.com/cyanheads/ris-austria-mcp-server/issues/52)), and escapes an ordinal ("1. Oktober") only where it would open a list item ([#60](https://github.com/cyanheads/ris-austria-mcp-server/issues/60)); the `ris://document` resource follows.

## Security

- **`ris_lookup_citation` parses citations in linear time**: its norm and gazette-number patterns were quadratic, so one long citation could hold the server's CPU for minutes.
