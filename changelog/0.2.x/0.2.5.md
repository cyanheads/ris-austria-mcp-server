# 0.2.5 — 2026-07-26

## Fixed

- **`ris_search_gazette` `resolveFederalTier()`** — routes federal queries by the publication-date interval instead of a single start year, so a `published_from`/`published_to` range crossing 2004-01-01 or 1945-01-01 is rejected locally with a new `cross_tier_range` error naming the interval, the tiers it spans, and the boundary dates to split at, rather than silently served by whichever tier the start year happened to name. A one-sided bound counts as spanning, since it is open into every tier beyond it. A range falling entirely in the uncovered 1941–1944 break stays a zero-hit success with a notice. `part: pre_1997` and a year-bearing `number` still name the tier outright and are never rejected. ([#11](https://github.com/cyanheads/ris-austria-mcp-server/issues/11))
- **`ris_search_gazette` zero-hit notice** — the federal `postwar` (BgblPdf) and `imperial` (BgblAlt) eras now build separate notice fragments instead of one shared string. BgblPdf's fragment names its own 1945–2003 window and the `part: pre_1997` guidance for pre-1997 issues; BgblAlt's carries the pre-1848 floor and the metadata-only/`alex_url` caveat, which previously leaked into BgblPdf results. ([#24](https://github.com/cyanheads/ris-austria-mcp-server/issues/24))
- **`ris_list_reference` topic `gazette_parts`** — notes now state that one call serves one era tier and name the 1941–1944 coverage gap, replacing the prior claim that a range auto-routes across tiers.
