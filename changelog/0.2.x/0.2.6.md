# 0.2.6 — 2026-07-31

## Fixed

- **`ris_lookup_citation` collection_number route** — `parseCollection` now emits a court-specific `Sammlungsnummer` filter: VfGH/UVS keep the bare number (matched dotted or undotted), VwGH gets the label plus the undotted number closed with a space-anchored trailing wildcard (`VwSlg 18000 A*`), since VwGH stores the full labelled undotted cite and a bare or dotted number matches nothing there. A VwSlg citation with no part letter that matches more than one distinct collection number (the A administrative and F finance series reuse numbers) now returns `found: false` naming both cites instead of silently resolving to the first hit. `collectionGuidance` and the `collection_number` `.describe()` on `ris_search_case_law` now state the per-court accepted form. ([#25](https://github.com/cyanheads/ris-austria-mcp-server/issues/25))
- **`ris_lookup_citation` state gazette route** — a `LGBl.` citation now probes `LgblAuth` and falls back to the legacy `Lgbl` series (`LgblNO` for Niederösterreich, named in guidance rather than probed since it carries no `Lgblnummer` param) on zero hits, resolving a citation that predates that Bundesland's e-Recht switch. `resolution_note` names the serving application, scope, and `state_era: legacy` when the fallback answered; an upstream error on the first probe throws rather than falling through to the second. ([#27](https://github.com/cyanheads/ris-austria-mcp-server/issues/27))
- **`ris_lookup_citation` gazette miss guidance** — `gazetteGuidance` now composes per route from the parsed citation instead of one fixed string sent to all four miss sites: the state-hint sentence appears only when the hint is missing, the part sentence only on the two federal tiers that carry a part split (and now reports whether a part filter was actually applied), and the Bundesland's legacy-series guidance only on the state route. An unparseable gazette number gets its own guidance, since no tier was ever searched.

## Changed

- `citation-formats.ts` and `courts.ts` reference entries corrected to state the per-court `Sammlungsnummer` form and the state-gazette legacy-series fallback.
