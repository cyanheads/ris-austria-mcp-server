# 0.2.0 — 2026-07-16

## Added

- **`state_era: 'current' | 'legacy'`** on `ris_search_gazette` — an explicit series selector for state scopes, replacing the removed `include_non_authentic` boolean below. `current` (default when omitted) searches the authentic `LgblAuth`; `legacy` searches the state's earlier non-authentic series (Niederösterreich's systematic `LgblNO`, or the historical `Lgbl` for the other Bundesländer); Wien carries neither. ([#7](https://github.com/cyanheads/ris-austria-mcp-server/issues/7))
- **`scope_filter_mismatch` now also rejects `series: 'ordinance_gazette'` combined with `state_era: 'legacy'`** — the Verordnungsblätter (Vbl) have no legacy counterpart, so RIS carries the authentic series only.

## Removed

- **`ris_search_gazette`'s `include_non_authentic: boolean` input** — its name and description promised an additive "include," but the handler switched the served application outright (`LgblAuth` → `Lgbl`/`LgblNO`), discarding every authentic result whenever set. ([#7](https://github.com/cyanheads/ris-austria-mcp-server/issues/7))
- **Breaking, and silent for un-migrated callers**: Zod strips the removed key from input, so a caller still sending `include_non_authentic: true` after upgrading gets no error — `state_era` is treated as omitted, and the call now returns authentic (`LgblAuth`) results instead of the historical records it was getting before. Migrate to `state_era: 'legacy'` to keep receiving them.
