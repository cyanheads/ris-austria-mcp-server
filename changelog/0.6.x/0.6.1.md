# 0.6.1 — 2026-10-30

## Added

- **`ris_get_document` and `ris://document/{application}/{documentNumber}` read PDF text** ([#97](https://github.com/cyanheads/ris-austria-mcp-server/issues/97)): `format: markdown` on a document whose only rendition is a PDF (`Mrp`, `Upts`, `Bvb`, `GrA`, `KmGer`, and draft companions filed without HTML) returns the extracted text with a `--- Page N of M ---` line before each page and a notice naming the PDF. New output field `text_source` (`html` | `pdf`). A scanned PDF, one over 16 MiB, or one that cannot be fetched in time returns a notice with the PDF URL instead.

## Changed

- **`ris_get_document` markdown writes image references as absolute URLs on the content host** ([#91](https://github.com/cyanheads/ris-austria-mcp-server/issues/91)), and a rendition holding only page images reads its PDF's text, keeping the image URLs with a notice when the PDF has none.
- **`page_size` notice** says this server serves pages of 10 or 20 documents, not that RIS pages do ([#95](https://github.com/cyanheads/ris-austria-mcp-server/issues/95)).

## Fixed

- **`ris_lookup_citation` checks a VfSlg/VwSlg cite's year** ([#90](https://github.com/cyanheads/ris-austria-mcp-server/issues/90)): a cite whose year disagrees with the decision returns `found: false` naming the cite the number does match.
- **A yearless VfSlg number that names two decisions is ambiguous** ([#100](https://github.com/cyanheads/ris-austria-mcp-server/issues/100)): `found: false` naming each (VfSlg 8, 11, 35, and 60 each name a 1919–1920 decision and a 1921 one).
- **`ris_get_document` returns `document_not_found` for an unknown document number on a PDF-only application** ([#97](https://github.com/cyanheads/ris-austria-mcp-server/issues/97)), where it returned a link to a missing PDF.
- **A reversed date window on the six search tools returns an empty page with a notice and no RIS request** ([#92](https://github.com/cyanheads/ris-austria-mcp-server/issues/92)); the notice gives the swapped bounds.
- **`ris_search_announcements` discloses undated rows under `in_force_as_of`, `entered_force_from`, and `entered_force_to`** ([#96](https://github.com/cyanheads/ris-austria-mcp-server/issues/96)): RIS returns every document with no entry-into-force date for any date, and the notice counts them on the page.
- **`ris_search_legislation` discloses undated versions under a one-sided force window** ([#98](https://github.com/cyanheads/ris-austria-mcp-server/issues/98)): `entered_force_to` alone and `left_force_from` alone.
- **`ris_get_document` notices escape the caller text they quote** ([#88](https://github.com/cyanheads/ris-austria-mcp-server/issues/88)): unmatched `sections` names and the `document_number` inside URLs no longer render as Markdown in `content[]`.
- **`ris_list_reference` escapes summaries, notes, and table cells in `content[]`** ([#94](https://github.com/cyanheads/ris-austria-mcp-server/issues/94)).
