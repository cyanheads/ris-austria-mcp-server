# 0.6.2 — 2026-11-09

## Added

- **`ris_get_document` and `ris://document` read a record's `document_url` and `eli`** ([#111](https://github.com/cyanheads/ris-austria-mcp-server/issues/111)): an ELI or `Dokument.wxe` web view (over `https` or `http`) is read for the document it names, drafts included.
- **`ris_lookup_citation` resolves an RIS ELI link** ([#110](https://github.com/cyanheads/ris-austria-mcp-server/issues/110)): a consolidated-law ELI returns that provision, an authentic-gazette ELI that entry.
- **`ris_lookup_citation` resolves a Rechtssatz number** ([#104](https://github.com/cyanheads/ris-austria-mcp-server/issues/104)) ("RS0022961", "RIS-Justiz RS0022961 [T3]", "RW0001127") through Justiz. Justiz case-law records gain `rechtssatz_numbers` (headnotes) and `legal_areas`.
- **`ris_lookup_citation` resolves a string of several gazette cites by its first cite and names the rest** ([#106](https://github.com/cyanheads/ris-austria-mcp-server/issues/106)), as a consolidated record's `promulgation` joins them.
- **Gazette records carry `application`** ([#105](https://github.com/cyanheads/ris-austria-mcp-server/issues/105)), the code `ris_get_document` takes with `document_number`.
- **Consolidated-law records carry `original_gazette`, `latest_change_gazette`, and `latest_change_relation`** ([#109](https://github.com/cyanheads/ris-austria-mcp-server/issues/109)).
- **Court and application codes are accepted in any letter case, and a state by its German or English name** ([#107](https://github.com/cyanheads/ris-austria-mcp-server/issues/107)). `RIS_FOLD_INPUT_SPELLINGS=false` restores strict validation, state names included.

## Changed

- **`ris_search_case_law` searches a `norm` article under every spelling RIS indexes** ([#108](https://github.com/cyanheads/ris-austria-mcp-server/issues/108)) (`Art6`, `Art 6`, `Artikel 6`), and the notice names the expression sent. A value carrying `(`, `)`, or `"` is sent as written, and its zero-hit advice says how to search every spelling.

## Fixed

- **`ris_get_document` keeps quoted headings inside the article that quotes them** ([#103](https://github.com/cyanheads/ris-austria-mcp-server/issues/103)): they no longer split an amending act and stay out of the outline. A `sections` name an earlier outline gave a quoted heading (`Artikel 129` on `BGBLA_2012_I_51`) still returns that passage, ending at the close of its quotation, with a notice.
- **`ris_lookup_citation` no longer reads an ELI as the gazette cite its path spells** ([#110](https://github.com/cyanheads/ris-austria-mcp-server/issues/110)): a refused path that spells a gazette cite, including the pre-1997 forms with no part (`/eli/bgbl/1974/60`, likewise `rgbl`, `stgbl`, `gbloe`), followed only by date, language, or format segments resolves as that cite. A provision's path cut before its document number (`/eli/bgbl/i/1999/165/A2P4`) returns `found: false`, `kind: unknown` with no request, where it returned the whole act's gazette entry.
- **`ris_lookup_citation` finds VwSlg cites VwGH stores in another Sammlungsnummer shape** ([#99](https://github.com/cyanheads/ris-austria-mcp-server/issues/99)) ("VwSlg 0017 F/1947", "VwSlg 1809/50") through one more search within the cited year, and a letter that differs from the stored one is named in the hint.
- **`.` and `..` as a `document_number` are refused before any fetch** on `ris_get_document` and `ris://document`.
- **A malformed `%` escape in a `ris://document` URI is a params rejection**, and a percent-encoded document number is decoded before it is checked.
