# 0.6.0 — 2026-10-28

## Added

- **`ris-austria-guide` Agent Skill**, served over MCP as `skill://ris-austria-guide/SKILL.md` (`createApp({ skills })`, mcp-ts-core 0.13.18) and shipped in the npm package, Docker image, and `.mcpb`: the identifier chains, gates, and Austrian legal-research conventions that span several `ris_*` tools. `tools/list` is unchanged.
- **Agent Plugins root `plugin.json` and `mcp.json`** (mcp-ts-core 0.13.18 scaffold).

## Changed

- **Enrichment-trailer string values in `content[]` render as code spans** (mcp-ts-core 0.13.18, [cyanheads/mcp-ts-core#785](https://github.com/cyanheads/mcp-ts-core/issues/785)): `**appliedInForceAsOf:** 2026-10-28` now reads ``**appliedInForceAsOf:** `2026-10-28` ``, likewise `application`, `changedFrom`/`changedTo`, and `servedApplication`. `structuredContent` is unchanged.
- **README Getting started and Running the server** are restructured (hosted and local `claude mcp add`, one stdio config block, GHCR `docker run`), and the `ris_lookup_citation` reference bullets are split by cite shape.
- **`docs/design.md`**: a bill's `abbreviation` matches `ris_search_legislation` `title` only when the bill enacts a new standing law in force on the searched date; an amending bill has no consolidated entry of its own.
- **Framework skills and scripts are synced to mcp-ts-core 0.13.18**: `.mcpbignore` lists every dev path with a root anchor, the bug-report form collects server version, mcp-ts-core version, runtime, transport, and OS in one Environment table, and `bun run test:coverage` is new.

## Dependencies

- Dev: `@biomejs/biome` 2.5.15 → 2.6.3, `ignore` ^7.0.13 → ^7.0.14, `tsc-alias` ^1.9.8 → ^1.9.9, `@vitest/coverage-istanbul` 5.0.5 (new).
- Transitive: `hono` 4.13.13 → 4.13.14, `fast-copy` 4.2.0 → 4.3.1, `postcss` 8.5.31 → 8.5.32, `magic-string` 1.4.3 → 1.4.5, `argparse` 3.0.3 → 3.0.4, `@babel/parser` 7.29.9 → 7.29.11, `@babel/types` 7.29.8 → 7.29.11, `@babel/helper-string-parser` 7.29.7 → 7.29.11.
