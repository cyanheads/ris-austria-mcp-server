# 0.3.0 — 2026-07-31

## Added

- **`ris_search_drafts` `materials`** — records now carry the companion documents filed with a draft (Erläuterungen, Textgegenüberstellung, Vorblatt/WFA, the Begleitschreiben covering letter, and Attachment annexes) as `{type, name, urls}`. Coverage is per-record; `type` is `Material`, `Letter`, or `Attachment` and is the reliable discriminator — `name` is free text RIS varies across records. Empty when the ministry filed none. ([#26](https://github.com/cyanheads/ris-austria-mcp-server/issues/26))
- **`ris_get_document` companion-document fetch** — `document_url` now accepts a `Materialien_`/`Schreiben_`/`Anlagen_` filename (a `materials[].urls` entry) and fetches it inside the parent document's folder instead of rejecting it — previously the only route to these documents. `content_urls` for a companion carries its own XML/HTML/PDF; RTF is present on roughly 40% of them and there is no `.pdfsig`. `RisService.buildDocumentContentUrl` gains an optional `contentName` parameter, held to the same safe-character pattern as the document number. ([#26](https://github.com/cyanheads/ris-austria-mcp-server/issues/26))
- **`ris_search_drafts` and `ris_search_announcements` `document_url`** — both records now carry the RIS web view (`Allgemein.DokumentUrl`), matching `ris_search_gazette` and `ris_track_changes`. It is the only browsable surface for the PDF-only `council_minutes` collection and for `ministerial_decrees`. ([#32](https://github.com/cyanheads/ris-austria-mcp-server/issues/32))

## Changed

- **`ris_get_document` outline budget** — `OUTLINE_BUDGET_BYTES` (now exported) lowered from 500,000 to 40,000 bytes, re-derived against 61 live renditions sampled across nine applications. The prior threshold was calibrated before the screen-reader-twin strip roughly halved rendered byte counts, so it had stopped firing on the multi-hundred-KB bills it was sized for. The budget bounds only markdown carrying at least two §/Artikel/Anlage headings — a rendition without them (most court decisions, many gazette and announcement bodies, all raw html/xml) returns whole at any size. ([#31](https://github.com/cyanheads/ris-austria-mcp-server/issues/31))
- **Partial-section-match notice** — no longer tells the caller to re-call `ris_get_document` without `sections:[…]` for an outline, since that re-call only returns one for documents over the budget. It now names candidate section names to copy verbatim for the re-call instead. ([#31](https://github.com/cyanheads/ris-austria-mcp-server/issues/31))
