# 0.4.2 — 2026-08-24

## Added

- **MCP 2026-07-28 compatibility** — the server now supports the current protocol alongside 2025-era clients, with one-hour public caching for immutable catalogs and 24-hour public caching for RIS document resources.

## Changed

- **Tool contracts** — undeclared root input fields now reject instead of being stripped, and output schemas advertise the structured error envelope so validating clients can accept both success and failure results.
- **Error recovery** — RIS client rejections now use `ValidationError`; request deadlines preserve `Timeout` recovery while correlated service requests inherit the handler context.
- **HTTP sessions** — source runs, containers, and documented configuration now resolve explicitly to stateless mode. MCP 2026-07-28 requests remain sessionless in either mode.
- **Maintenance surface** — Bun 1.4 container and package-manager pins, production peer omission, test typechecking, framework skills, community health files, and generated documentation are current.
